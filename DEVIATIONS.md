# Deviations from Standard Defaults

Every intentional deviation from default Build Standard v1.2.0 or toolchain expectations is recorded transparently here.

| ID | Area | Deviation | Rationale & Mitigation |
|---|---|---|---|
| **DEV-01** | `A27` (GitHub Pages demo) | Marked `n/a` in `repo.yaml` | AUTOPHAGE executes live x86-64 RWX machine code (`VirtualAlloc`/`mmap`) inside a native C11 binary streamed by `web/server.mjs` over loopback (`127.0.0.1:8787`). Static GitHub Pages cannot host native x86-64 RWX execution. Static SVG preview (`docs/media/social-preview.svg`) and full PDF preprint (`dist/Donahue_2026_autophage.pdf`) are shipped directly in the repo. |
| **DEV-02** | `A28`, `A41`, `B02` (`package: false`) | Zero external package manager manifest (`package.json` / `Cargo.toml` / `pyproject.toml`) | Zero third-party runtime dependencies in C11, Node.js, Python scripts, or Lean 4 (`0` Mathlib). Toolchain pinning is enforced via `lean/lean-toolchain` (`leanprover/lean4:v4.35.0`) and `lean/lake-manifest.json`, while `examples/` is still provided (`examples/run_quick_experiment.py`). |
| **DEV-03** | Windows Local Lean 4.35.0 Kernel #6 (`lean4lean` / `bwrap`) | 5/6 independent checkers run locally on Windows; full 6/6 + `lake check --paranoid` + `lake comparator --paranoid` run on Ubuntu Linux CI | Upstream `lean4lean.exe` cannot parse Windows `.olean` path headers and `lake check`/`lake comparator` require Linux `bubblewrap` (`bwrap`). Documented transparently in `results/lean4-multi-kernel.txt`, `LIMITATIONS.md`, and `paper/main.tex`. |
| **DEV-04** | `B23`, `B24`, `B25` (TLA+, verified impl language, CBMC/Kani) | Marked `n/a` in `repo.yaml` | Formal protocol and algebraic proofs are carried out in Pure Lean 4.35.0 (`B22`); C11 bare-metal JIT requires C11/x86-64 machine emission rather than a verified implementation language, and memory/UB safety is guarded by ASan/UBSan (`B16`), 1M-exec canary fuzzing (`T05`), libFuzzer (`B15`), and Lean mask-inbounds proofs (`T26`, `T27`). |
| **DEV-05** | `v1.2.0` → `v1.4.0` epoch SHA-256 delta on `03_abiogenesis` / `04_feral` | 4 of 11 sampled epoch hashes in `03_abiogenesis_zero_seed.txt` and final hashes in `04_feral_vs_constitutional.txt` shifted after commit `1f39157` added `-ffp-contract=off` while every integer/metric count remained identical (`bench` SHA-256 `4bd29f39...3c20612` stayed 100% identical across all platforms). | Disabling FMA contraction (`-ffp-contract=off`) removes compiler-specific 1-ULP rounding variance in Kahan-Neumaier FP64 accumulators (`k_heat_radiated_kj`), improving cross-compiler determinism. All `results/` artifacts were regenerated live from `v1.4.0` so current files match the current binary 100%. |
